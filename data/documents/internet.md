# NovaTel Internet Packages

## Fiber 300

The Fiber 300 package provides up to 300 Mbps download speed
and 100 Mbps upload speed.

The package uses a fiber-optic connection.

A compatible router with Gigabit Ethernet support is recommended.

## Fiber 500

The Fiber 500 package provides up to 500 Mbps download speed
and 100 Mbps upload speed.

The package uses a fiber-optic connection.

A compatible router with Gigabit Ethernet support is required.

## Fiber 1000

The Fiber 1000 package provides up to 1000 Mbps download speed
and 500 Mbps upload speed.

The package uses a fiber-optic connection.

A router with at least one Gigabit Ethernet port is required.

Wi-Fi 6 is recommended when using the service over Wi-Fi.

## Installation

Fiber internet installation requires an available fiber connection
at the customer's address.

A NovaTel technician performs the standard installation.

The customer must provide access to the location where the
fiber termination equipment will be installed.

## Internet Speed

The advertised speed represents the maximum theoretical speed
of the selected package.

Actual speed may be lower depending on network conditions,
the customer's equipment, Wi-Fi signal quality and network load.

Ethernet connections generally provide more stable performance
than Wi-Fi connections.

## Service Availability

Fiber internet is only available at addresses where the
NovaTel fiber network has been deployed.

Customers can check service availability before ordering
an internet package.
